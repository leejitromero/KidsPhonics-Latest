# Answer choice artwork

The four original user-provided choice PNGs are used unchanged. Their order is blue, green, purple, orange. AnswerChoiceButton scales away most transparent outer margins at rendering time and places live text/pictures within the cream center.

Colors are decorative, independent of correctness. A check or retry badge communicates the result. Shared game choices, alphabet/word tiles, and Memory Flip use these frames. Existing sounds, disabled callbacks, scoring, and picture content are preserved.
