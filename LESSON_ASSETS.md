## Practice and rhyming update

Practice This Letter now uses only the supplied vocabulary, three-frame artwork,
and new word recordings. Its five questions cover initial-letter spelling,
picture/letter association, word selection, spoken-word recognition, and a
missing initial letter. This avoids substituting hard-G or /ks/ questions for
Giraffe or Xylophone. The five-answer scoring and 4/5 mastery threshold remain.

Hear Word is compact and teal; answer cards use distinct colors and a two-column
layout that expands to one column for enlarged text. Lessons use a compact
Wigloo guide and a smaller colored difficulty picker. Game Zone keeps its
existing presentation through opt-in lesson styling.

Previous, Grid, and Next share one colored row in both letter views. Short Vowel
Sounds no longer offers Practice This Letter.

With the user's approval, rhyming cues now use supplied picture words (Cat,
Hat, Sun, Ball, Fish, Nest, Van, Kite, Queen, Whale) with their new recordings.
Every cue animates; choices use matching animation only when artwork exists,
otherwise text. Easy/Medium/Hard retain 4/6/7 rounds and 3/4/5 choices.
No old emoji or image is rendered in these lesson activities. Older shared
assets needed by Game Zone remain. No APK was built for this update.
