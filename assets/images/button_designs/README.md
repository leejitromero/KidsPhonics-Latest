# Supplied lesson button artwork

The eight PNGs are unchanged originals from the user's `button designs.zip`.
Next and Sound each have three variants; Previous has two. They are bundled for
offline use by `LessonControlButton` in Letter Recognition, Letter Sounds, CVC
Words and Blending Sounds. A mounted button randomly chooses one applicable
variant and keeps it while the page updates. Live labels remain below the artwork
for text scaling and screen readers; disabled controls dim the artwork.

Try Again and A–Z Grid have matching native icon buttons because the ZIP does not
contain artwork for these actions. The red/yellow/blue puzzle reference was
attached separately without a local file path; `BlendingPuzzlePiece` draws a
matching native jigsaw treatment rather than claiming to embed that original PNG.
