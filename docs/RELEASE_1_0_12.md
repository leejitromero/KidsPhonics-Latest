# KidsPhonics 1.0.12, build 13

Parents Overview now shows the weekly summary, recommended Quick Check and a link to detailed Progress. Overall Letter Mastery and duplicate letter details remain in Progress. The compact overview fits the verified 390×844 layout without scrolling.

Leaving Parents for Quick Check or detailed Progress ends parent access, restores learner screen-time counting and requires the PIN on return. Failed startup reads offer Retry without replacing saved progress, and a failed reset write displays its pending-save status. Sound Match's difficulty preview correctly describes three letter choices.

This release also includes the colorful Quick Check buttons, updated Home layout, compact Progress and Parents cards, and the animated Magical Sound Orb.

Delivery: [KidsPhonics-1.0.12-build13.apk](../releases/KidsPhonics-1.0.12-build13.apk).

Verification: [release report](../tools/release_1_0_12_verification.json). Full static analysis found no issues; 504 full-suite tests and 8 final Parents exit regression checks passed. Reviewed source hashes match the release. Source inputs were captured before compilation and checked afterward, and bundled assets were compared with their local source bytes.

The APK retains the existing development signing certificate. Physical-device installation, microphone and speaker checks remain on the [manual checklist](../MANUAL_TEST_CHECKLIST.md).
