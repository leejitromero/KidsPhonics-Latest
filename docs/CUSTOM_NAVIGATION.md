# Custom KidsPhonics navigation

The nine original PNGs from `newbuttons.zip` are registered under
`assets/images/custom_navigation/`. They were copied without editing; their
original SHA-256 hashes and file sizes are recorded in
`tools/custom_navigation_assets.json`.

`KidsNavigationBar` displays Home, Progress, Parents, and Settings in equal
cells above the wooden base. All images use `BoxFit.contain`; transparent
margins remain intact. The bar uses a bottom SafeArea and a maximum width of
560 logical pixels. Home and category content reserve its measured height,
while their backgrounds still fill the screen.

Taps animate to 0.95 scale for 85 ms, return for 85 ms, select the matching
glowing image, and fade the destination page over 250 ms. Repeated taps are
ignored during the transition. Reduced-motion settings skip these animations.

`MainNavigationShell` owns one stationary footer and lazily retains each
visited page, including its internal tab and scroll state. Activity routes
inherit `MainNavigationScope`, so their existing menu returns to those same
pages. Android Back returns to Home from another main tab. Lessons and Games
keep their existing activity navigation and character/cloud entry behavior.

Settings reuses the existing Parent Settings controls through
`SettingsScreen`; it keeps Parent PIN protection. Authentication is shared
between Parents and Settings and ends when returning to Home or Progress.
Learner data continues to use the existing provider and persistence system.

Verification includes exact asset hashes, active states, press/fade timing,
repeated taps, retained page state, PIN protection, activity-menu returns,
Android Back, and six phone/tablet viewports with system insets. Phone and
tablet renders are generated by `test/kids_navigation_test.dart` under
`build/ui_previews/update_custom_navigation_390.png` and
`build/ui_previews/update_custom_navigation_768.png`.
