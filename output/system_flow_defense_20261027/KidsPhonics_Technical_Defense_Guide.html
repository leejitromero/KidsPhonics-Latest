03 Data storage and save flow

What is the database?

SABIHIN: “SharedPreferences ang storage mechanism namin. Local key-value persistence ito; hindi MySQL, SQLite o Firebase. Ang complex progress structures ay kino-convert sa JSON strings bago i-save.”

Saved information

Implementation example

Authoritative app state

appStateV1: profile, preferences, XP/stars, progress and other app-state values.

Letter assessment history

letterAdventuresV1: completed count, best/latest responses, mastery, timestamp and last session identity.

Lesson / activity evidence

wordLessonProgressV1, letterProgressV2 and dailyActivityV1.

Parent gate

parentPinHashV1 stores the salt and digest together; the authenticated session is not persisted.

Screen time

screenTimeStateV1 plus compatible keys for daily usage, limit, extra time and bypass state.

 

Load → validate → update → save

Startup obtains SharedPreferences and decodes the saved state. Typed defaults and validation handle invalid values. A load failure exposes Retry; the app does not intentionally overwrite an unreadable save with an empty learner state.

PreferenceWriteQueue serializes snapshot writes, skips unchanged values, and retries a failed operation up to three times. AppProvider first writes one authoritative appStateV1 JSON value, then mirrors compatibility keys. Unsaved state can expose Retry.

Important boundaries

• This is not a multi-user transactional server database. The snapshot/save queue reduces inconsistent or out-of-order writes; it is not a guarantee against every hardware/storage failure.

• No custom cloud backup/sync is implemented. Clear Data, uninstall or device loss can remove local progress; OS backup/restore behavior is separate.

Code / reference: AppProvider._loadPrefs / _savePrefs; lib/services/preference_write_queue.dart; lib/models/word_lesson_progress.dart

04 Assessment, rewards and recommendation

Actual mastery rule

PASS = five completed first responses
AND correct count >= 4
AND Letter sounds is correct
AND Sounds in words is correct

Example

Interpretation

4/5, both sound tasks correct

Passes the implemented mastery policy.

4/5, one sound task wrong

Does not pass; high total alone is insufficient.

Incomplete check

Not a completed assessment. Guided retries do not overwrite first-response evidence.

Mastered before; lower result later

Latest result can change, while prior mastery and best score remain retained.

 

Duplicate prevention and rewards

AdventureSession has an ID; completeAdventure rejects a repeated completion for the recorded same session ID. It also guards first completion and first mastery. First completed check = 5 XP; first mastery adds 25 XP and 1 star. Repeating mastery does not repeatedly award those milestones.

Games keep their own scoring/reward paths. For example, Flappy completion is not proof of assessed phonics mastery. Replaying a sound or opening Progress does not itself earn mastery.

Recommendation is rule-based

The current unmastered target remains selected. For another target, prioritize completed-but-unmastered checks, lower latest score and alphabetical order. All mastered → letter review selection. Walang trained recommendation model.

Level = floor(XP / 200) + 1. Streak uses actual dates with scored answers or speaking attempts; speech statistics remain separate from ordinary answer accuracy.

05 Images, audio and animation

Bundled resources

Images, recordings and fonts are stored under assets/ and declared in pubspec.yaml. Data catalogs map each letter, word or instruction phrase to a local file. The learner does not download the whole lesson library during a normal session.

Component

What it does

PhonicsAudioService

Resolves phrase/letter/word keys to local recordings and coordinates playback. No text-to-speech fallback is claimed.

AudioService / background music

Separate sound-effects and music behavior, controlled by saved preferences.

Frame animation

Ordered local images are displayed over time. AnimationController/timers and lifecycle checks drive frame changes; this is not generative animation at runtime.

Decode / preload controls

precacheImage and ResizeImage reduce repeated loading and request suitable image decode sizes. This does not change the original source image bytes.

Lifecycle / accessibility

Covered or backgrounded activities pause relevant motion/playback. Reduced Animations can use a static frame; text scaling has layout support.

 

Why is the APK large?

It includes many local images and recordings, plus Flutter/native libraries for three CPU architectures in the universal package. The recorded corrected APK is 515,866,438 bytes: about 515.9 decimal MB or 492.0 MiB. This is APK file size, not a measurement of runtime RAM or installed app-data usage.

Deleting output/home_classroom removed about 175.6 MB of PC-only exports/previews. Those files were outside the runtime asset bundle, so their deletion did not reduce the APK.

SABIHIN: “Offline availability has a storage trade-off. We can explain the asset footprint honestly; deleting design previews outside the bundle does not optimize the installed app.”

KIDSPHONICS / JJCM / 07

06 Speech-recognition technical flow

Request microphone permission

↓

Initialize device recognizer and choose supported English locale

↓

Listen → receive recognized words and final-result status

↓

Normalize words → compare with the expected target

↓

Record valid practice result or show retry / support guidance

What comparison is actually performed?

matchesSpokenWord lowercases and extracts complete word tokens. Easy/Medium can accept the target as a complete word within a phrase. Hard compares the normalized whole target with the normalized whole recognized result. It does not accept an arbitrary substring inside a different spelling.

Preferred supported English locales are tried in order en_US, en_PH, en_GB, then another supported English locale. The listening request uses a five-second listenFor value and two-second pauseFor value; the device service can still determine actual availability/behavior.

Limits to explain clearly

• This is word-recognition practice, not phoneme-level accuracy measurement, accent grading, a clinical assessment or a custom-trained AI model.

• Microphone permission and compatible speech-service/language support are required. The app does not force an on-device-only recognition option, so do not guarantee offline speech or that recognition audio never leaves the device.

• No speech / no match / speech timeout can show Retry without counting an empty input as a wrong spoken answer. Permission denial and unavailable service have separate guidance.

Code / reference: lib/services/speech_practice_service.dart; lib/screens/voice_recognition_screen.dart; AndroidManifest.xml

07 Parent PIN and daily screen time

Mechanism

Actual implementation

PIN validation

Exactly 4 numeric digits; matching confirmation; rejects 0000, 1111, 1234 and 4321 at setup/change.

PIN storage

Random.secure creates a 24-byte salt. The digest is SHA-256 of salt + colon + PIN. Salt and digest are stored together, not the plain PIN.

Failed entry limit

Five failed verifications cause a 30-second lockout. The failure/session state is in memory, not a permanent server-side throttle.

Authenticated parent session

Not saved as a permanent authenticated login. Leaving the area ends it; lifecycle logic can expire it after extended backgrounding.

Daily allowance

A global foreground clock tracks usage; daily limits are 15/30/45/60/90 minutes. Parent-authenticated time is excluded from normal learner counting.

Time limit reached

Global TimeLimitOverlay blocks access and pauses covered tickers. A parent can add 10/15/30 minutes or bypass for today.

Protected reset

Requires an authenticated parent session and explicit confirmation. It is not part of ordinary startup or normal exit.

 

What security can we claim?

SABIHIN: “May local parental gate kami na may salted PIN hash at temporary lockout. Hindi plaintext ang naka-store na PIN. Pero hindi ito bank-grade authentication o encrypted cloud account system.”

A salted fast SHA-256 digest is not a password-stretching KDF such as Argon2/PBKDF2. SharedPreferences is not encrypted secret storage. A four-digit local gate should be described as parental control within the project scope, not protection against every compromised/rooted-device attack.

ScreenTimeService uses a queued snapshot and periodic checkpoints; date handling is local to the device. Walang remote time-authority service sa current app.

What the test types mean

• Unit tests: data transformations, assessment policy, matching rules and game-model behavior.

• Widget/regression tests: route behavior, interaction, layout, controls and repeated-action/lifecycle safeguards, often with mocked device services.

• Asset/package checks: file existence, declared assets, SHA-256 equality, APK metadata and signature. These do not prove the educational effectiveness of the content.

Do not overclaim

Automated success is not a guarantee of zero bugs. Real microphone recognition, audible sound quality, touch responsiveness, low-end memory/performance and accessibility need device observation. Educational improvement requires its own study/user evaluation; the code does not establish research outcomes.

10 Panel Q&A — implementation

Question

Short answer to practice

1. Anong programming language?

Dart ang main app language. Flutter ang UI framework; Kotlin ang maliit na native Android bridge.

2. Bakit Flutter?

Our current implementation uses reusable widgets and one Dart UI/state codebase. The tested delivery is Android; cross-platform capability is not proof that we already tested iOS.

3. Ano ang database ninyo?

SharedPreferences local key-value storage, with JSON snapshots for complex progress. Hindi MySQL, SQLite o Firebase ang current implementation.

4. Paano connected ang screens?

Flutter navigation handles routes; AppProvider/ChangeNotifier shares learner state. Screens call app logic/services, and subscribed widgets rebuild.

5. May backend/API server ba?

Walang sariling learner-account backend or cloud database. Native MethodChannel is a Dart-to-Android bridge, not a web API server.

6. Paano hindi nadodoble ang reward?

Assessment completion uses session identity and first-completion/first-mastery conditions. Other games have their own accepted-action and completed-state guards.

7. AI ba ang recommendation?

No trained model: it retains the current target until mastery and selects another using recorded completion, latest score and alphabetical order.

8. Paano ang errors sa saving?

Queued writes and checked return values; retry attempts and an unsaved-state signal. User-facing Retry is available instead of falsely reporting a successful save.

 

A useful answering pattern

Name the technology → explain its role in this app → give a concrete example → state the scope or limitation. Halimbawa: “Provider ang shared state; pag-save ng Quick Check result, nare-refresh ang Progress. Hindi ito cloud synchronization.”

Kapag hindi mo maalala ang exact implementation detail, sabihin kung anong source file ang nagha-handle nito. Huwag manghula ng algorithm, database o external service.

11 Panel Q&A — scope and readiness

Question

Short answer to practice

9. Offline ba lahat?

Local ang content and saved progress. Speech recognition depends on the installed device service, permissions and English support; we do not guarantee offline recognition on every phone.

10. Pronunciation grader ba ito?

No. It compares recognized word tokens with the expected word. It does not measure phoneme quality, accent or clinical speaking ability.

11. Bakit malaki ang APK?

Bundled visuals/recordings and native libraries for three ABIs. APK bytes, installed storage and RAM are different measurements.

12. Paano pinoprotektahan ang Parents?

Four-digit local PIN, random salt plus SHA-256 digest, temporary lockout and nonpersistent authenticated session. It is a local parental gate, not hardened enterprise authentication.

13. Paano nagiging mastered?

Five first-response tasks; at least 4/5 correct plus both sound tasks correct. Game completion and lesson exposure do not independently satisfy this rule.

14. Ano ang mangyayari sa uninstall?

There is no custom cloud recovery. Local data can be lost; OS backup behavior is outside the app-specific storage design.

15. Ready na ba sa defense?

The recorded automated checks passed and the user reported a successful phone test. We still rehearse the exact demo route and keep an APK/video backup.

16. Ano ang puwedeng future work?

Measure educational outcomes, broaden device testing and plan asset-size/distribution improvements. These are future directions, not claims that they are already implemented.
