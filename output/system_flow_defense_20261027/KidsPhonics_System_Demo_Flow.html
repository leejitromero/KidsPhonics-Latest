KIDSPHONICS / JJCM / 01

System Demo Flow

A practical walkthrough for the JJCM defense team

KidsPhonics is an interactive learning app for Grade 1 learners. Pinagsasama nito ang letter recognition, letter sounds, basic word practice, games, Quick Check, progress tracking at parent controls.

Opening script — about 30 seconds

SABIHIN: “Magandang araw po. Kami ang JJCM. Ipapakita namin ang KidsPhonics: isang Android learning application na nagbibigay ng guided phonics practice, interactive activities at malinaw na progress information para sa learner at parent.”

Main system route

Open app → Load saved profile, preferences and progress

↓

First use: introduction + learner setup | Returning use: Home

↓

Home → Lessons / Games / Recommended Quick Check

↓

Practice or assessment → Feedback → Save eligible progress

↓

Progress / Parents / Settings → Return or continue learning

Global rule: kapag naabot ang enabled daily time limit, puwedeng takpan ng parent-unlock screen ang anumang activity.

What is included

Scope

Lessons

6 learning modules

Games

11 practice games; may Easy, Medium at Hard options

Quick Check

5 activities for a selected letter; may explicit mastery rule

Bottom navigation

Home, Progress, Parents, Settings — apat na tabs lamang

 

Prepared 27 October 2026. Ito ay presentation guide, hindi bagong feature specification. Ang expected values ay nakadepende sa existing learner data.

KIDSPHONICS / JJCM / 03

02 Demonstrate the six lessons

Route: Home → Lessons → select a module → listen/interact → Next/Previous or Back. Hindi kailangang tapusin muna ang lahat ng lessons bago maging available ang Quick Check.

Module

What to show and explain

1. Letter Recognition

Uppercase/lowercase letter presentation. I-tap ang speaker at lumipat ng letra; ipaliwanag ang pagkilala sa written letter.

2. Letter Sounds A-Z

Letter-sound recordings. Ipakita na iba ang letter name sa sound na ginagamit nito sa salita.

3. Short Vowel Sounds

A, E, I, O at U. I-demo ang isang short-vowel recording at sample content.

4. Alphabet & Pictures

Letter + example image, gaya ng A–ant. Pakinggan ang “A is for ant”; Next automatically plays the next example recording.

5. CVC Words

Guided consonant–vowel–consonant practice. May 17 words sa current lesson; per-word practice completion ang sinusubaybayan.

6. Blending Sounds

Guided blending and word puzzles. May 22 words sa current lesson; pagsasama-sama ng sounds para mabuo ang word.

 

Recommended short demo

Buksan ang Letter Recognition para sa isang letra. Pakinggan ang name; pagkatapos ay ipakita ang corresponding sound. Buksan ang Alphabet & Pictures at gamitin ang Next. Kung may oras, tapusin ang isang CVC/blending example.

SABIHIN: “Sa lessons, nagbibigay tayo ng modeled examples at guided practice. Ang pakikinig o pag-view ng lesson ay hindi agad katumbas ng mastery; may hiwalay tayong Quick Check para sa assessment.”

Actual listening at valid word completion ang basehan ng ilang practice counters. Opening a page alone does not establish mastery. Hindi lahat ng listening event ay nadaragdag sa streak.

KIDSPHONICS / JJCM / 04

03 Quick Check and mastery

Route: Home/Progress/letter practice → selected or recommended letter → complete five activities → See Result → save the result.

Activity

Learner action

1. Big and little letters

Match the letter with its correct lowercase/uppercase relationship.

2. Letter sounds

Listen and choose the matching letter.

3. Missing letters

Choose the missing target letter in the shown word.

4. Sounds in words

Identify the picture/word for the target sound scope.

5. Letter hunt

Find all four target-letter positions; incorrect selections affect the first-response hunt result.

 

Exact mastery rule

At least 4 of 5 first responses must be correct, AND both Letter sounds and Sounds in words must be correct. Halimbawa: 4/5 pero mali ang Letter sounds = hindi pa mastered. Ang guided retry ay hindi pumapalit sa unang assessment answer.

SABIHIN: “Hindi basta mataas na game score ang tinatawag naming mastered. May limang skill checks, at kailangan ding tama ang dalawang sound activities.”

Result and continuation

Ipakita ang result. Depende sa result at recommendation, may Continue, Try Again, Practice these skills, Review Lesson, View My Progress o Back to Home. Ang Review Lesson ay letter-specific guided review; hindi nito nire-rescore ang completed check.

Condition

Expected recording / reward

First completed check for a letter

5 XP; dagdag na 25 XP at 1 star kung first mastery rin.

Same completed session submitted again

Walang duplicate XP/star award.

Later lower score / partial check

Retained ang existing mastery at best score; updated ang latest completed result. Hindi sine-save bilang completed check ang partial session.

KIDSPHONICS / JJCM / 05

04 Games — first six activities

Route: Home → Games → optional category filter → choose game → choose difficulty → read/listen to instructions → play → result, replay or return. Puwedeng i-disable ng parent ang Games.

Game

What the learner does / demo point

1. Flappy Letters

Tap to fly through A–Z. Ipakita ang ready/pause/continue flow at letter cues. Motor activity completion ito; hindi automatic letter mastery.

2. Sound Match

Listen and select the matching letter from choices. Accepted wrong retries are included in answer statistics; correct-round rewards are protected from duplicate taps.

3. Memory Flip

Flip cards and find matching pairs. Ipakita ang preview, pairs at timer; covered/backgrounded gameplay should not consume active play time.

4. Phonics Quiz

Listen to a prompt and choose an answer. I-demo ang speaker replay at visible correct/incorrect feedback.

5. Word Builder

Fill the missing letter positions using letter tiles. May word audio at feedback; hindi ito kapareho ng pag-arrange ng lahat ng letters sa Rumbled Words.

6. Speak & Recognize

Listen to the example and say the target word. Kailangan ng microphone permission, supported English locale at working device speech service.

 

What to say before playing

SABIHIN: “Ang games ay practice activities para sa letters, sounds at words. May sariling mechanics at difficulty ang bawat game. Ang game rewards ay hiwalay sa assessed letter mastery sa Quick Check.”

Compact live demonstration

Mag-demo ng isang listening game, halimbawa Sound Match. Pakinggan ang prompt, sagutin, ipakita ang feedback, at kumpletuhin ang short round kung may oras. Sa ibang games, puwedeng ipakita ang instructions at isang interaction upang hindi humaba ang presentation.

Hindi pare-pareho ang scoring at round length ng lahat ng games. Huwag ipangakong bawat button press, replay o pagbukas ay nagbibigay ng rewards.

Code / reference: lib/screens/games_screen.dart; corresponding game screens; lib/data/game_session_order.dart

KIDSPHONICS / JJCM / 06

05 Games — remaining activities

Game

What the learner does / demo point

7. Alphabet Order

Arrange letters in sequence. Current tiers: Easy A–F, Medium A–M, Hard A–Z.

8. Missing Vowel

Choose the missing A/E/I/O/U in a word. Ipakita ang Listen Again, feedback at Next.

9. Picture Match

Listen to the target and choose the matching picture. Ipakita ang replay at response feedback.

10. Rumbled Words

Arrange the available letters to spell the pictured word. May Hear Word, Erase at one hint per word; napiling letters are read by letter name.

11. Rhyming Words

Find words that belong to the same rhyming family/jar. Ipakita ang rhyme relationship, hindi lamang parehong first letter.

 

How to explain difficulty

Easy/Medium/Hard ay game-specific settings. Halimbawa, Flappy changes travel speed; Alphabet Order changes letter range. Maraming task-based games use a shuffled pool and short session lengths, pero huwag itong ipaliwanag bilang universal rule para sa lahat.

Speech demo: reliable and honest

Action

Expected response

Listen to the target; allow the microphone

Available English speech support is checked before listening.

Speak clearly; wait for a final result

Recognized words are compared with the target. Easy/Medium allow the target within a phrase; Hard expects the target alone.

No speech / denied permission / unsupported service

May Retry, permission guidance o unavailable message. No-speech is not automatically scored as a wrong spoken answer.

 

SABIHIN: “Ang activity na ito ay word-recognition practice. Gumagamit ito ng speech service ng device; hindi namin ito tinatawag na clinical pronunciation assessment o sariling trained AI model.”

Subukan ang speech service sa mismong demo phone bago ang defense. Hindi garantiya ang availability ng speech recognition kapag walang internet; nakadepende ito sa device service at language support.

KIDSPHONICS / JJCM / 07

06 Progress, rewards and recommendation

Progress tab

What to show

My Journey

My Phonics Skills, learning summary, streak at recommended practice. I-tap ang skill para bumalik sa kaugnay na lesson o letter practice.

My Letters

A–Z with New, Explored, Practiced at Mastered filters. Purple = not yet mastered; green frame with check = mastered. Tap for latest/best result and practice route.

My Rewards

Badges, Alphabet Milestones at My Treasure. Ipakita ang requirements at earned state; ang pag-view lang ay hindi nagbibigay ng bagong reward.

 

Eight achievement goals

First Letter Mastery; Vowel Star; CVC Explorer; Blending Champion; 3-Day Streak; 5 Letters Mastered; Halfway There; Alphabet Master. Galing sa saved learning evidence ang earned states.

Important metrics

Metric

Meaning

Mastered letters

Passed the current Quick Check policy; hindi basta binuksan ang lesson.

Streak

Consecutive days with scored answers or speech practice; hindi simpleng app opening.

Level

floor(total XP / 200) + 1. Stars at XP are motivation counters, not clinical reading scores.

Recommended Practice

Saved target remains until mastery. New target selection prioritizes attempted-but-unmastered letters, lower latest score, then alphabetical order.

 

SABIHIN: “Dito nakikita ang pagkakaiba ng exposure, practice at mastery. Ang recommendation ay transparent at rule-based gamit ang saved results; hindi ito machine-learning prediction.”

Evidence to demonstrate

Pagkatapos ng completed Quick Check, buksan ang selected letter sa My Letters. Ihambing ang latest/best score at status. Kung already mastered ang demo letter, ipaliwanag kung bakit hindi muling tumataas ang first-mastery reward.

KIDSPHONICS / JJCM / 08

07 Parents and protected controls

Route: Parents → set up a four-digit PIN if none exists, or unlock the saved PIN → Overview / Activity / Settings. Local parent gate ito, hindi online parent account.

Area

Demonstration

PIN entry

Use the correct PIN privately. May confirmation sa setup; rejected PINs stay on authentication. After five failed checks, may 30-second lockout.

Overview

This Week at a Glance: learning activity, questions, accuracy and related summary information.

Activity

Weekly Activity, Daily Breakdown, speech-practice statistics and Rewards summary. I-expand ang isang day para makita ang recorded details.

Settings

Protected game access, daily time limit and PIN controls. Reset Progress is a separate confirmed destructive action; huwag itong gamitin sa live demo.

 

Game-access example

I-toggle ang game access off, bumalik sa Games at ipakita ang blocked state. Pagkatapos ay i-unlock muli ang Parents at ibalik ang dating setting upang makapagpatuloy.

Daily-time-limit behavior

Available daily limits: 15, 30, 45, 60 or 90 minutes. Kapag reached, may global blocking overlay. Valid parent authentication can add 10, 15 or 30 minutes, or allow the rest of today, then resume the activity.

SABIHIN: “Ang parent controls ay hindi lang display settings. Naka-check ang access bago makapasok sa game, at global ang time-limit guard para hindi malusutan sa paglipat ng screen.”

Hindi kailangang hintayin ang 15-minute limit habang nagde-demo. Ipakita ang setting at prepared recording ng reached-limit behavior kung kapos sa oras. Huwag baguhin ang device clock para piliting mag-trigger.

08 Settings, saving and continuity

Feature

What to explain / show

Sound & Music

Voice Assistance, Sound Effects, Background Music at music volume. Ibalik ang demo volume pagkatapos mag-toggle.

My Character

Change the existing learner character/name. One local learner profile per current installation; hindi separate cloud accounts.

Display & Animations

Text size at Reduced Animations. Ipakita ang readable layout; hindi kailangang baguhin ang whole device settings.

Replay / Help / About

Replay Introduction; Help & Tutorials; About KidsPhonics with purpose, features at JJCM credits.

 

Prove that data persists

Tandaan ang isang completed result o setting. Isara at buksan ang app sa karaniwang paraan; pagkatapos ay buksan ang Progress/Settings. Expected: naroon pa ang successfully saved state. Huwag gumamit ng Clear Data o uninstall para sa test na ito.

SABIHIN: “Naka-save sa device ang profile, preferences at learning progress. Hindi kailangan ng email account para magamit ang learning content. Wala kaming sariling cloud-sync o multi-device restore sa current scope.”

Offline scope and recovery

• Bundled lesson/game images at recorded audio ay local. Walang runtime font download na kailangan sa current startup configuration.

• Speech recognition is a device-service exception: test its language support and offline behavior separately.

• Kapag may save warning, gamitin ang Retry at hintaying mawala ang warning. Kapag walang listening input, gamitin ang speech Retry; hindi kailangang i-reset ang buong app.

Deleting output/home_classroom exports only freed PC storage. Hindi sila runtime backgrounds at hindi iyon nagpapaliit ng installed APK.

Short panel answers

Question

Suggested answer

Bakit may lessons at games?

Lessons model the skill; games provide practice; Quick Check separately assesses letter mastery.

Paano nagiging mastered?

At least 4/5 first responses, including correct Letter sounds and Sounds in words.

May internet/account ba?

No app account is required. Core assets and saved progress are local; device speech support may vary.

Paano nakita ang progress?

Saved activity evidence drives status, recommendations and reports. Viewing a report does not award progress.

 

SABIHIN: “Iyon po ang buong learning cycle: guided lessons, interactive practice, assessment, saved progress at parent monitoring. Ang app ay learning support tool; ang educational effectiveness ay dapat suportahan ng hiwalay na user evaluation o research evidence.”

Gamitin ang kasamang Technical Defense Guide para sa language, framework, architecture, data storage, audio, speech, security at testing questions.
